# SteelCodeCore

A multiloader library for **Minecraft 1.21.1** (Fabric + NeoForge, via Architectury) that lets you declare blocks,
items and gameplay features **once, in `common`**, and get them registered on both loaders with every JSON
generated by datagen.

```java
public final class MyContent {
    public static final CoreRegistry REG = SteelCodeCore.registry("mymod");

    public static final RegistrySupplier<CreativeModeTab> TAB =
            REG.tab("main").icon(() -> MyContent.RUBY.main().get()).title("My Mod").build();

    // Every shape of vanilla gold (stairs, slab, wall, door, button...) without a single new texture
    public static final BlockFamily GOLD = REG.family().base(Blocks.GOLD_BLOCK).createAll().build();

    // A full gem: ruby, ruby_block, ore, deepslate ore, recipes, c: tags, tools and armor
    public static final MaterialSet RUBY = REG.material("ruby").gem()
            .tools(ToolStats.DIAMOND).armor(ArmorStats.DIAMOND).generate(4, 3, -64, 16).build();

    public static void init() {
        REG.register();   // from your common initializer
    }
}
```

That is the whole mod: names, models, blockstates, loot tables, recipes, recipe-book unlocks, tags and world
generation are written by datagen and work on both loaders.

## What you get

| Area | Features |
|---|---|
| [Blocks](blocks.html) | Single blocks with light, XP, drops, fuel and behaviour; families of 20 shapes; dye colors; copper-like weathering; amethyst-like crystals; connected and random textures; containers, lamps, ladders, falling blocks |
| [Items](items.html) | Items with food, tooltips and use/hit lambdas; creative tabs; complete metals and gems; tools, armor, bows, crossbows, fishing rods, shields, horse armor; smithing templates |
| [World](world.html) | Wood sets with trees, signs and boats; crops; flowers and bushes; ores, blobs, boulders, disks and geodes; wolf, painting, trim, banner and music-disc variants |
| [Effects](effects.html) | Status effects, potions with brewing recipes, data-driven enchantments |
| [Data](data.html) | Recipes and recipe templates, loot injection, trades, advancements, multi-language names, a config file |
| [Gameplay](gameplay.html) | Typed networking, persistent player and world data, key bindings, HUD, commands, statistics, advancement triggers |
| [Compat](compat.html) | JEI, REI and EMI info pages and hiding; Jade and WTHIT tooltips — all optional |
